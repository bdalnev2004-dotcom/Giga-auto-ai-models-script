# Как начать тестирование

Порядок выбран так, чтобы каждый шаг проверялся отдельно и падал понятно.
Ничего из этого ещё **ни разу не запускалось** — код писался и проверялся чтением,
поэтому первые прогоны наверняка вскроют мелочи.

---

## Шаг 0. Поставить то, чего нет

Проверено на этой машине: **ничего из списка не установлено**. `python` в PATH —
это заглушка Microsoft Store, не интерпретатор (печатает «Python» и выходит).

| Что | Зачем | Откуда |
|---|---|---|
| **Python 3.12** | сам бот | python.org — при установке отметить **Add python.exe to PATH** |
| **ffmpeg** | уникализация | `winget install Gyan.FFmpeg`, затем **перезапустить терминал** |
| **Docker Desktop** | Postgres и Redis | docker.com — нужен только для шага 2 |

Проверка — все три команды должны напечатать версию:

```bash
python --version && ffmpeg -version && docker --version
```

Если `python --version` печатает просто «Python» — сработала заглушка Store.
Лечится в «Параметры → Приложения → Псевдонимы выполнения приложения»: выключить
переключатели для `python.exe` и `python3.exe`.

## Шаг 1. Уникализация — без ключей и без базы

Самая быстрая проверка: ничего внешнего не нужно, только ffmpeg.

```bash
cd giga-bot
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

Возьмите любой mp4 и прогоните:

```bash
python -m services.uniquify_service test.mp4 out.mp4 --account 3
```

Ожидаемый вывод — строка «Готово» с перечнем применённых правок
(обрезка, яркость, контраст, шум, скорость).

**Что проверить глазами:** `out.mp4` должен визуально не отличаться от исходника.
Если разница заметна — уменьшите диапазоны в `build_recipe` в
`services/uniquify_service.py`. Если запустить с тем же `--account 3` ещё раз,
параметры будут **те же** (они детерминированы), а с `--account 7` — другие.
Это и есть механика «у каждого аккаунта свой почерк».

## Шаг 3. Ключи

```bash
copy .env.example .env
```

Заполнить в `.env` минимум:

| Переменная | Где взять |
|---|---|
| `TELEGRAM_BOT_TOKEN` | @BotFather → `/newbot` |
| `ANTHROPIC_API_KEY` | console.anthropic.com → API Keys |
| `DATABASE_URL` | `postgresql+asyncpg://giga:devpassword@localhost:5432/giga_farm` — совпадает с дефолтом в `docker-compose.dev.yml` |
| `REDIS_URL` | `redis://localhost:6379/0` |
| `VAULT_ENCRYPTION_KEY` | сгенерировать (см. ниже) |

Ключ шифрования генерируется, а не покупается:

```bash
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

`GOOGLE_SERVICE_ACCOUNT_JSON` можно **оставить пустым** на этом этапе — тогда
папки в Drive не создадутся, но бот про это честно скажет и продолжит работать.

Проверить всё разом:

```bash
python scripts/healthcheck.py
```

Отсутствующий ключ покажет `SKIP`, а не уронит проверку.

## Шаг 4. Запуск бота

```bash
python bot.py
```

При старте создастся схема БД. Дальше — в Telegram, своему боту.

### Сценарий проверки по шагам

**1. Создать аккаунт.** Напишите `создать блогершу`.
Бот проведёт интервью на 15 вопросов с нумерацией `1/15`. Отвечайте коротко, но
на вопросе про внешность — подробно: это описание зафиксируется и пойдёт во все
будущие генерации фото.

*Что проверяем:* аккаунт создан под правильным именем (раньше сюда попадал ответ
про стиль), в конце показан номер аккаунта.

**2. Генерация текста.** Напишите `био`.
Бот задаст 3 вопроса и выдаст варианты с пометками, чем каждый отличается.

*Что проверяем:* варианты действительно разные по подходу, а не переформулировки;
уложились в 150 символов; звучат голосом персонажа из интервью.

**3. Цикл правок.** Ответьте `❌`, затем напишите замечание словами.
*Что проверяем:* новая партия учитывает замечание, а не повторяет прежнее.

**4. Уникализация.** Пришлите боту mp4 (до 20 МБ), затем напишите `уникализировать`.
*Что проверяем:* бот скачал файл, обработал, вернул с номером и списком правок;
если Drive настроен — файл лёг в `16_уникализировано`.

## Что заведомо не работает

Это не баги, а незаконченные места — чтобы вы не искали причину:

- **Публикация в Instagram.** Аппрув пишет «уйдёт на публикацию», но реального
  вызова нет. Нужны логин аккаунта, файл сессии и прокси.
- **Монтаж (Vyra).** Тупик: авторизация только через браузер, headless не работает.
  Замена не выбрана.
- **Фото, лого, озвучка.** Higgsfield и ElevenLabs — заглушки.
- **📅 в аппруве.** Спросит дату, но не запомнит: следующее сообщение с цифрами
  уйдёт в отбраковку вариантов.
- **Сторис в 20:00.** Задача выполняется вхолостую.
- **Текущий аккаунт после рестарта.** Хранится в памяти процесса — нужно заново
  сказать `/account N`.

## Если что-то падает

**`integer out of range`** — не должно: колонки переведены в `BigInteger`. Если
всё же увидели, значит схема создана до этой правки: удалите базу и пересоздайте
(`docker compose -f docker-compose.dev.yml down -v`).

**`ffmpeg не найден`** — не перезапущен терминал после установки.

**`TypeError` про `output_config`** — старая версия SDK. `pip install -U anthropic`.

**Бот молчит на видео** — проверьте, что `media.router` подключён **до**
`scenarios.router` в `bot.py`: иначе catch-all перехватывает сообщения.
