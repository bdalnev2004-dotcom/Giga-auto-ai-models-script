# Локальный запуск

Проверено на этой машине: **Python 3.14.7 установлен, зависимости ставятся, все
26 модулей импортируются, 34 логических теста проходят.** Ниже — что осталось.

---

## Шаг 1. Проверить, что уже готово

Виртуальное окружение и зависимости уже установлены — я это сделал при проверке.
Убедиться:

```bash
cd giga-bot
venv\Scripts\python.exe scripts\selftest.py
```

Должно закончиться строкой `пройдено 34, провалено 0`. Ни ключей, ни базы, ни
интернета для этого не нужно — тест гоняет чистую логику.

Если окружения нет (например, вы клонировали репозиторий заново):

```bash
python -m venv venv
venv\Scripts\python.exe -m pip install -r requirements.txt
```

---

## Шаг 2. Поставить ffmpeg

Единственное, чего не хватает из инструментов. Без него не работают монтаж и
уникализация; всё остальное — работает.

```bash
winget install Gyan.FFmpeg
```

**После установки перезапустить терминал** — иначе PATH не подхватится. Проверка:

```bash
ffmpeg -version
```

Уникализацию можно проверить сразу, без бота и без ключей — возьмите любой mp4:

```bash
venv\Scripts\python.exe -m services.uniquify_service test.mp4 out.mp4 --account 3
```

Выведет список применённых правок. `out.mp4` должен выглядеть как исходник —
если разница заметна глазом, уменьшите диапазоны в `build_recipe`.

---

## Шаг 3. Поднять Postgres и Redis

```bash
docker compose -f docker-compose.dev.yml up -d
```

Если Docker ставить не хочется, есть путь без него — Postgres можно поставить
нативно, а Redis не обязателен: без `REDIS_URL` бот возьмёт хранилище в памяти
(диалоги не переживут перезапуск, но для проверки это терпимо).

## Шаг 4. Ключи

```bash
copy .env.example .env
```

Минимум, без которого бот не стартует — `config.py` требует их при импорте:

| Переменная | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | от @BotFather → `/newbot` |
| `ANTHROPIC_API_KEY` | console.anthropic.com → API Keys |
| `DATABASE_URL` | `postgresql+asyncpg://giga:devpassword@localhost:5432/giga_farm` |
| `VAULT_ENCRYPTION_KEY` | сгенерировать командой ниже |
| `GOOGLE_SERVICE_ACCOUNT_JSON` | путь к JSON; можно указать несуществующий — папки в Drive просто не создадутся, бот про это скажет |

```bash
venv\Scripts\python.exe -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

Проверить всё разом:

```bash
venv\Scripts\python.exe scripts\healthcheck.py
```

Незаполненный ключ даёт `SKIP`, а не падение.

## Что проверять в боте

**Создание персонажа.** `создать блогершу` → интервью на 15 вопросов.
На вопросе про внешность отвечайте подробно: это описание фиксируется и уходит
во все будущие генерации фото.

**Генерация.** `био` → 3 вопроса → варианты с пометками, чем отличаются.
Смотреть: разные ли они по подходу, уложились ли в 150 символов, звучит ли голос
персонажа.

**Цикл правок.** `❌` → замечание словами → новая партия должна учесть замечание.

**Обучение.** Утвердите вариант номером. Сгенерируйте то же самое ещё раз —
одобренный текст теперь подставляется как пример. Отклоните дважды с одинаковым
замечанием — оно станет постоянным правилом аккаунта.

**Редактор брифов.**

```
/brief                        список сценариев
/brief bio                    показать бриф
/brief bio avoid Не начинать с вопроса
/brief bio history            версии
/brief bio rollback 2         откатить
```

**Уникализация.** Пришлите mp4 (до 20 МБ) → `уникализировать`.

**Публикация.** Требует настоящий аккаунт Instagram и резидентный прокси:

```
/connect 1     прокси, логин, пароль, 2FA (сообщения с секретами удаляются)
/login 1       разовый вход, получить файл сессии
/status 1      что настроено, чего не хватает
```

Дальше: прислать готовый ролик → `монтаж` → утвердить номером → уйдёт в Instagram.
Между публикациями одного аккаунта стоит минимум 45 минут — защита от бана.

## Что заведомо не работает

Не баги, а незаконченное — чтобы не искать причину:

- **Редактирование карточки персонажа.** Создать можно, поправить — нет.
- **Якорный кадр для фото.** Поля в базе есть, команд нет. `generate_photo` без
  якоря намеренно падает с понятной ошибкой, а не выдаёт другого человека.
- **Сторис в 20:00.** Задача выполняется вхолостую — как и приём 📅 (дату теперь
  честно сохраняет, но забирать по расписанию некому).
- **Батч-отбраковка визуала** идёт тем же путём, что одиночный ❌.

Починено с прошлой версии этого файла (29.08): контекст аккаунта переживает
рестарт бота, 📅 больше не ломает следующий ввод, есть Alembic-миграции,
монтаж (`editor_service.py`) проверен на реальном ffmpeg-рендере.

## Если падает

**`ffmpeg не найден`** — не перезапущен терминал после установки.

**`ResolutionImpossible` при установке** — старый `requirements.txt`. Текущий
использует нижние границы вместо точных пинов; подтяните репозиторий.

**`integer out of range`** — схема создана до перехода на `BigInteger`.
Пересоздать: `docker compose -f docker-compose.dev.yml down -v`.

**`TypeError` про `output_config`** — старый SDK: `pip install -U anthropic`.

**Бот молчит на видео** — `media.router` должен подключаться **до**
`scenarios.router` в `bot.py`.
