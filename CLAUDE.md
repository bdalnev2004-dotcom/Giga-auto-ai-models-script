## Что это

Ферма ~20 Instagram-аккаунтов (AI-инфлюенсеры + бренды) под управлением Telegram-бота.
Генерация контента через AI, утверждение одной цифрой в чате, автопубликация Reels.

**Путь одной единицы контента:**
триггер в чате → контекст аккаунта → уточняющие вопросы → генерация → Google Drive
(нумерованные варианты) → аппрув номером/✅/❌ → публикация → аудит-лог.

## Ключевые договорённости (не переигрывать без спроса)

- **Постинг — только Instagram Reels, через `instagrapi`.** HikerAPI **не умеет публиковать**,
  это read-only API; ключ от него оставлен только для чтения/аналитики. Проверено по докам.
- **Vyra не годится для автоматизации.** Проверено по докам: авторизация только через
  OAuth в браузере (API-ключа нет), и нужен живой браузер с открытым проектом в редакторе —
  серверного рендера/экспорта нет. Headless-вызов из бота на VPS невозможен.
  Нужен другой инструмент монтажа (реалистичный вариант — ffmpeg у себя).
- **Веб-дашборда не будет.** Управление — Telegram-бот + CRM (Notion / Bitrix24 / Kommo,
  выбор ещё не сделан).
- TikTok/YouTube/VK — вне объёма. `blotato_service.py` лежит как заглушка на будущее,
  никуда не подключён.
- Фото/карусели/сторис генерируются и утверждаются, но автопостинг у них не запускается.

## Что нужно от пользователя

**Обязательные (без них `config.py` падает при импорте):** `TELEGRAM_BOT_TOKEN`,
`ANTHROPIC_API_KEY`, `DATABASE_URL`, `VAULT_ENCRYPTION_KEY` (генерируется через
`Fernet.generate_key()`, не покупается), `GOOGLE_SERVICE_ACCOUNT_JSON`.

**Для прода:** `REDIS_URL`, `POSTGRES_PASSWORD`, `GOOGLE_DRIVE_ROOT_FOLDER_ID`.

**По мере подключения:**
- `ELEVENLABS_API_KEY` — обычный REST API, ключ в личном кабинете. Проблем нет.
- `HIGGSFIELD_API_KEY` — API есть (`docs.higgsfield.ai`), но авторизация из **двух** значений:
  `Key <API_KEY_ID>:<API_KEY_SECRET>`. В `config.py` поле одно — при реализации адаптера
  нужно будет разнести на два.
- `VYRA_MCP_URL` — **ключа не существует**, см. раздел договорённостей. Поле в конфиге
  пока мёртвое.
- Уникализация — см. отдельный раздел ниже, ключа нет, нужен Telegram-юзербот.

**На каждый IG-аккаунт** (в зашифрованную таблицу `credentials`, не в `.env`):
логин, пароль, TOTP-секрет, **свой резидентный прокси** — общий IP на 20 аккаунтов
даёт массовый бан.

## Уникализация видео (шаг `uniquify`, папка `16_уникализировано`)

**Зачем:** Instagram матчит видео по перцептивному отпечатку. Один и тот же рилс на
нескольких аккаунтах фермы или перезалив удачного ролика → площадка распознаёт дубль,
режет охваты или не пропускает публикацию. Уникализация меняет отпечаток техническими
правками: обрезка кадра, лёгкий цветокор, шум, метаданные, иногда зеркало и скорость.

**Место в пайплайне:** финальный шаг, после монтажа, прямо перед публикацией.

**Два пути, решение не принято:**

1. **`@unikalizator_videobot`** (сторонний Telegram-бот, изначальный план). Наш бот
   написать ему **не может**: с 07.05.2026 Telegram разрешил bot-to-bot, но только при
   взаимном opt-in, а чужую сторону мы не контролируем. Значит нужен отдельный
   **юзербот** на Telethon/Pyrogram: `API_ID` + `API_HASH` с my.telegram.org, реальный
   номер телефона, файл сессии. Плюс зависимость от чужого сервиса — лимиты, доступность,
   смена формата ответа.
2. **ffmpeg у себя** — те же преобразования нативно, без ключей, без лишнего аккаунта,
   в том же контейнере. Разные параметры на аккаунт = разные отпечатки. Тот же инструмент,
   что предлагается вместо Vyra, — одна зависимость на оба шага.

**Честная оговорка:** ни один из вариантов не гарантия. Это снижение риска, а не защита —
детект у Instagram сложнее файлового хэша.

## Проверка ключей и сервисов

```bash
python scripts/healthcheck.py
```

Проверяет всё разом: Anthropic, Telegram, Postgres, Redis, Vault, Google Drive,
ElevenLabs, Higgsfield, HikerAPI — ключ на месте, отвечает ли сервис, что с подпиской
и остатком квоты. Отсутствующий ключ даёт `SKIP`, а не падение, так что запускать можно
на любой стадии настройки. Флаг `--json` — машиночитаемый вывод.

Намеренно **не** импортирует `config.py`: тот требует все секреты при импорте, и одного
недостающего хватило бы, чтобы уронить всю проверку.

Не покрывается: Vyra (авторизация только в браузере) и логин IG-аккаунтов
(дёргать нельзя — триггерит защиту Instagram).

## Риск, о котором помним

Публикация идёт через приватный API Instagram — это против правил платформы, и обойти нельзя:
официальный Graph API не умеет кликабельные ссылки в сторис. Блокировки будут; лимиты частоты
постинга в коде пока не реализованы.
